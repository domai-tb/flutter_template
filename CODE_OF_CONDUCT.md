# Code of Conduct

We want this project to be welcoming and respectful to everyone.

## Acceptable behavior

Be considerate, constructive, and respectful of differing views and experiences. Give feedback that focuses on ideas and behavior, not people.

## Unacceptable behavior

Harassment, discrimination, insults, intimidation, personal attacks, unwanted sexual attention, and publishing someone’s private information without consent are not acceptable. Disruptive behavior that prevents others from participating is also not acceptable.

## Scope of application

This code applies in project spaces, including issues, pull requests, discussions, and events, and when someone represents the project in public.

## Reporting procedures

Report concerns privately to a project maintainer using contact details on their GitHub profile. Do not report conduct concerns in a public issue. If no private contact is available, ask a maintainer for one without sharing sensitive details. If a maintainer is involved, contact another maintainer. Include what happened, when, where, and any relevant links. Maintainers will handle reports discreetly and will not share them beyond those who need to respond. Retaliation for making a good-faith report is not acceptable.

## Enforcement guidelines

Maintainers will review reports fairly and may take action based on the behavior and its impact. Actions may include a private warning, removal of content, temporary restrictions, or permanent exclusion from project spaces. Maintainers will explain decisions to the people directly involved when appropriate.
